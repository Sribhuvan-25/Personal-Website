SY.2026.SYS.02 Android / Kiosk

Chromebook Exam Client

Cognizant / Pearson · Contract

An Android exam client for Chromebooks written in Kotlin. Lock Task Mode pins the device to the test for its full duration, so the candidate cannot leave the app and the app cannot be backgrounded out from under the session.

A WebSocket media bridge carries camera and mic streams between the native shell and the exam web app. Play Integrity attestation runs before delivery, so the backend verifies the device is genuine and unmodified before an exam is ever released to it.

Device trust belongs on the server. Anything the client asserts about itself is a claim, not a fact, so the attestation gate sits in front of content release rather than inside the app.

SY.2025.SYS.03 Applied AI / Vision

Live Exam Vision & Tooling

Pearson VUE · Applied AI Engineer, Intern

Put Gemini 2.5 Flash on live exam video feeds and reached 92% detection on flagged behaviors at 30 FPS. Real time was the requirement, so the frame budget set the model choice rather than the other way around.

Built a cache-augmented generation pipeline so repeat policy lookups hit stored context instead of the model. Same answer, no inference bill, no drift between two readings of the same rule.

Shipped an MCP server and a LangGraph assistant that let an LLM read and write real scheduling tools rather than describe them.

An assistant that cannot act is a search box with better manners. I give models typed tools and a bounded surface, then judge them on what changed in the system.

Manifest

Acquisition criteria · What gets into this catalogue

04 clauses
Clause 01

Depth is the only defensible thing left.

Anyone can assemble breadth in an afternoon now. I would rather hold five objects I can defend at the level of a specific tradeoff than twenty I can only describe.

Clause 02

The boundary is the system.

Native to web, client to server, model to tool. Most real failures live at a seam that nobody claimed, so I claim them and write down what crosses.

Clause 03

Extension beats the fork.

New cases should plug into a shared contract. If the answer to a new requirement is a copied directory, the design already lost and the second copy will rot first.

Clause 04

Write the decision down, not just the code.

A threshold buried in a function is a rumor. Analytical choices belong in a readable record so someone can disagree with them on purpose.
