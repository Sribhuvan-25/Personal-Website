I work at the seam where native code meets the web layer. Right now that means proctoring clients that have to hold a locked exam session together on Windows, macOS and Android without the candidate noticing the machinery.

How I think software should be built

  • One source tree beats three. Platform forks feel fast for a quarter and cost you every quarter after.
  • The boundary is the product. Most hard bugs I have shipped and fixed lived in a bridge, not in either side of it.
  • Write the decision down. If the reasoning only exists in the code, it did not survive the next person.
  • A model is a dependency, not a plan. Cache what repeats, verify what matters, keep the trace.
